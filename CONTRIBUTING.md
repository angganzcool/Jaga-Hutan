# Panduan Kontribusi / Contributing to Jaga Hutan

Terima kasih atas minat Anda untuk berkontribusi pada **Jaga Hutan**! 🌲✨

## 🌟 Cara Berkontribusi

1. **Melaporkan Bug / Masalah**:
   - Buka menu [Issues](https://github.com) dan gunakan template laporan bug yang jelas.
   - Sertakan log kesalahan dan koordinat lokasi jika relevan.

2. **Mengajukan Fitur Baru**:
   - Silakan diskusikan ide fitur Anda melalui Issues terlebih dahulu sebelum membuat Pull Request besar.

3. **Mengembangkan Kode (Pull Request)**:
   - Buat branch baru dari `main`:
     ```bash
     git checkout -b feature/nama-fitur
     ```
   - Pastikan seluruh unit test lolos:
     ```bash
     python test_simulation.py
     ```
   - Buat commit dengan pesan yang deskriptif.
   - Kirimkan Pull Request ke cabang utama.
